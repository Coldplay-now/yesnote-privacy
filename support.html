4. 数据与隐私

爱记笔记采用本地优先设计：

  • 所有笔记保存在设备本地（iOS UserDefaults / Android DataStore），不上传任何服务器
  • 没有账号系统、没有云同步、没有分析 SDK
  • 分享卡片是 PNG 图片，仅在你主动调用系统分享时生成与传输
  • 升级检查只读取 GitHub Releases 公开 API，不带任何用户标识

更多说明请查看 隐私政策。

5. 常见问题

笔记会同步到云端吗？

不会。所有笔记保存在本机，卸载即清空。如果需要备份，请用「设置 → 导出笔记」生成 Markdown 或 JSON 文件，自行存到 iCloud / 网盘 / 微信。

误删的笔记能恢复吗？

可以。删除的笔记会保留 30 天，从「设置 → 数据 → 回收站」可以恢复或永久删除。30 天后自动清空。

iOS 版本和 Android 版本功能一致吗？

核心功能（笔记列表、标签、搜索、分享卡片、回收站、导出、新手引导）保持一致；少量交互按各自平台习惯做了适配。

分享卡片里的字符是乱码 / 缺字？

分享卡片用 LXGW 文楷字体，对极少数生僻字可能没收录。换个相似的常用字即可，或者把那段话换个写法。

Android 升级横幅没有出现？

App 启动后会异步检查 GitHub Releases，命中后 6 小时内不重复请求。如果你刚装完最新版本又快速发布了下一版，可能要等下次冷启动 + 6 小时节流过完才会看到提示。也可以直接从本页或 Releases 页面手动下载。
