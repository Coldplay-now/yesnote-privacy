隐私政策

最后更新：2026-05-23

爱记笔记（YES NOTE）是一款本地优先的笔记 App。我们极其在意你的隐私，所以做得很简单： 我们不运行任何服务器，看不到你的笔记内容，也不收集你的任何使用数据。

我们收集什么

简单回答：不收集任何个人数据。

  • 不要求注册账号，没有用户系统，没有我们运营的后端。
  • 不上传你写下的任何笔记内容到我们这里。
  • 不内置任何第三方分析、广告、崩溃上报或追踪 SDK。所有 crash 信息由 Apple TestFlight / App Store Connect 与 Google Play 内部聚合，我们仅看到聚合后的去标识统计。
  • 不读取通讯录、位置、麦克风、相册（除下方一项例外）等敏感权限。

笔记存在哪里

  • iPhone / iPad / Mac：笔记保存在 Core Data SQLite 文件中，位于 App Group 容器 group.com.yesnote.xt。如果你登录了 iCloud 且 App 的 iCloud 同步开关打开， 数据会镜像到你 Apple ID 名下的私有 CloudKit 容器 iCloud.com.yesnote.xt。 这个容器是你的私有空间，Apple 不会让我们读到内容，我们也没有任何方式访问它。
  • Android：笔记保存在 Android Jetpack DataStore Preferences 中， 位于 App 沙盒里。Android 端目前不提供云同步。

我们不调用任何 AI 服务

从 3.3 / 1.11 起，App 显式做了以下事情来保证笔记文本不离开你的设备：

  • iOS / iPadOS / macOS：编辑器所有文本字段（标题 / 正文 / 标签）显式调用 .writingToolsBehavior(.disabled)，关闭 Apple Intelligence 写作工具。 这意味着笔记文本不会进入 Apple 的 Private Cloud Compute，也不会被发送到可选的 ChatGPT 集成。
  • Android：App 本身不调用 OpenAI / Gemini / Claude 或任何其它远端 AI 服务。 系统输入法的本地建议（Gboard 等）由系统控制，本 App 不读取也不上传任何键盘事件。

权限使用

  • iCloud 容器（iOS / iPadOS / macOS）：用于跨设备同步同一 Apple ID 下的笔记。 完全可选；在系统设置 → Apple ID → iCloud 中可以单独关闭。
  • 相册写入（仅 iOS）：当你点击「保存到相册」时， 仅将 App 内生成的分享卡片图片写入你自己的照片库。我们不读取你已有的任何照片。
  • 文件读写：用于导出 Markdown / JSON 备份、导入 .txt / .md 文本文件、 以及拖入 / 拖出 笔记（macOS Finder 双向拖拽）。所有读写都通过系统文件选择器，由你授权。

数据迁移与删除

  • 导出：设置 → 数据 → 导出笔记，支持 Markdown（可读）或 JSON（完整备份）两种格式。
  • 删除本地数据：卸载 App 即完全清除本机所有笔记 + 所有偏好设置。
  • 删除 iCloud 数据：在系统设置 → Apple ID → iCloud → 管理账户存储 → 爱记笔记 → 删除数据，可单独清空云端容器；不影响其它设备的本地副本（直到那些设备也同步一次）。

政策变更

如果未来这份政策有变化，会在 App 的「设置 → 隐私 → 查看完整隐私政策」入口以及本页顶部 「最后更新」时间体现。涉及实质变化的会在 App 内通过更新弹窗或 release notes 主动告知。
